College Event Participant Registration System

📌 Overview

The College Event Participant Registration System is designed to manage event registrations efficiently. It allows participants to register for events, checks event capacity, and maintains participant status.

---

🎯 Features

- Participant Registration
- Event Selection
- Capacity Checking
- Registration Status Management
- Organized Data Handling

---

🏗️ System Components

1. Entities

- Participant
  
  - Participant ID
  - Name
  - Email
  - Phone Number

- Event
  
  - Event ID
  - Event Name
  - Date
  - Capacity

- Registration
  
  - Registration ID
  - Participant ID
  - Event ID
  - Status (Confirmed / Waiting)

---

🔄 Workflow

1. Participant enters details
2. Selects an event
3. System checks event capacity
4. If seats available → Registration Confirmed
5. If full → Added to waiting list
6. Status is stored and displayed

---

🧠 Algorithm (Summary)

1. Start
2. Input participant details
3. Select event
4. Check event capacity
5. If capacity available → Confirm registration
6. Else → Add to waiting list
7. Store registration details
8. Display status
9. End
